# Project Governance

Treqna follows a Benevolent Dictator For Life (BDFL) governance model combined with open community contribution principles.

## Roles & Responsibilities

### Benevolent Dictator For Life (BDFL)
The Lead Engineer serves as the final authority on technical decisions, architectural breaking changes, and public API stability commitments.

### Core Maintainers
Core maintainers have commit access to the primary repository and review code contributions. Maintainers enforce architectural rules, code formatting guidelines, and test coverage requirements.

### Contributors
Anyone who submits issues, documentation updates, or pull requests is a contributor.

## Decision Making Process

1. Major proposals require an architectural decision issue or draft proposal prior to implementation.
2. Maintainers review proposals for alignment with the Universal Data Model architecture.
3. If consensus cannot be reached, the Lead Engineer makes the final decision.
