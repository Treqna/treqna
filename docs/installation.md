# Installation Guide

Treqna targets Python 3.11, 3.12, and 3.13.

## Installing via pip

```bash
pip install treqna
```

## Installing via uv

```bash
uv add treqna
```

## Development Installation

To install Treqna from source for local development:

```bash
git clone https://github.com/treqna/treqna.git
cd treqna
pip install -e .[dev]
```

Verify your installation:

```bash
treqna --version
```
