# Maintainers Roster

This document lists the maintainers responsible for the governance, code review, release management, and security of Treqna.

## Core Maintainers

| Name | GitHub Handle | Role | Area of Responsibility |
| --- | --- | --- | --- |
| Lead Engineer | `@treqna/lead` | BDFL / Core Lead | Architecture, Core Engine, Planning System |
| Plugin Lead | `@treqna/plugins-lead` | Plugin Maintainer | Format Descriptors, Official Plugins |
| DevOps Lead | `@treqna/devops` | Release Maintainer | CI/CD, PyPI Releases, Security |

## Maintainer Responsibilities

- **Code Review**: Ensure all pull requests meet strict zero-comment, complete typing, and quality standards.
- **Triage**: Respond to incoming issue reports within 48 hours.
- **Security**: Monitor vulnerability reports and publish security patches.
- **Release Management**: Sign tags and manage PyPI distribution.
