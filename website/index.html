Engine Architecture & Features

Core capabilities powered by Treqna's Universal Data Model and pure Python standard library.

Universal Data Model (UDM)

Normalizes relational, document, key-value, and hierarchical data into a unified intermediate node tree, guaranteeing zero loss across transformations.

Zero External Dependencies

Built 100% with standard library modules (csv, json, xml.etree, zipfile). Ultra-secure, portable, and instant to deploy without pip bloat.

20/25 Compatibility Matrix

100% verified accuracy across 20 core format conversion pairs, with Excel driver currently in active Beta development.

Extensible Driver SDK

Scaffold custom format drivers in seconds with a single CLI command: treqna create-driver myformat. Includes base classes and test scaffolding.

Inspection & Auto-Detection

Inspect payloads instantly with treqna.detect() and treqna.inspect(). Returns confidence scores, schemas, field types, and syntax errors.

High-Throughput Streaming

Stream 100,000+ records seamlessly with minimal memory overhead using chunked parsing.
